## Executive Summary

The Digital Classroom platform uses **Google Firebase Firestore** as its primary database, combined with **Firebase Storage** for file management. The database is designed to support:

- **Multi-role system**: Students, Teachers, and Admins
- **Class-based learning**: Organized by classroom codes
- **Subject management**: Hierarchical subject organization
- **Content delivery**: Assignments, Notes, and Quizzes
- **Assessment tracking**: Submissions and grades
- **Real-time synchronization**: Live data updates across users

### Key Metrics
- **Collections**: 11+ NoSQL collections
- **Storage Buckets**: 1 primary Firebase Storage bucket
- **Auth Provider**: Google Sign-In + Email/Password
- **Security Model**: Role-based access control (RBAC)

```
│  - Firebase Auth (Authentication)       │
│  - Cloud Rules (Security)               │
└─────────────────────────────────────────┘
```

### Data Tier Architecture

**Three-tier data organization:**

1. **Root Level Collections** (Direct access)
   - users
   - classes
   - assignments
   - quizzes
   - notes
   - attendance
   - notifications

2. **Subcollections** (Nested under parent documents)
   - classes/{classCode}/joinRequests
   - classes/{classCode}/students

3. **Transaction Collections** (Submission tracking)
   - assignmentSubmissions
   - quizSubmissions
   - gradeRecords

## Security & Access Control

### Role-Based Access Control (RBAC)

#### Student Role
```
READ ACCESS:
  ✓ Own user profile
  ✓ Enrolled class details
  ✓ Assignments in enrolled class
  ✓ Assignment submissions (own only)
  ✓ Quizzes in enrolled class
  ✓ Quiz submissions (own only)
  ✓ Notes in enrolled class
  ✓ Own attendance records
  ✓ Own grade records
  ✓ Notifications (own)

WRITE ACCESS:
  ✓ Update own profile
  ✓ Create assignment submissions
  ✓ Create quiz submissions
  ✗ Modify assignments
  ✗ Modify notes
  ✗ View other students' work

DELETE ACCESS:
  ✓ Own submissions (before grading)
  ✗ Assignments
  ✗ Classes
```

#### Teacher Role
```
READ ACCESS:
  ✓ All users in enrolled class
  ✓ Own class details
  ✓ All assignments in own class
  ✓ All submissions for own assignments
  ✓ All quizzes in own class
  ✓ All quiz submissions for own quizzes
  ✓ All notes in own class
  ✓ Class attendance records
  ✓ Student grades in own class
  ✓ All notifications for own class

WRITE ACCESS:
  ✓ Update own profile
  ✓ Create/update assignments in own class
  ✓ Create/update quizzes in own class
  ✓ Create notes in own class
  ✓ Update submission grades and feedback
  ✓ Update quiz submission feedback
  ✓ Record attendance
  ✗ Delete other teachers' content

DELETE ACCESS:
  ✓ Own assignments
  ✓ Own quizzes
  ✓ Own notes
  ✗ Delete class
  ✗ Delete teacher approvals
```

#### Admin Role
```
READ ACCESS:
  ✓ All users
  ✓ All classes
  ✓ All assignments
  ✓ All submissions
  ✓ All quizzes
  ✓ All quiz submissions
  ✓ System analytics

WRITE ACCESS:
  ✓ Update any user profile
  ✓ Approve/Reject teacher requests
  ✓ Disable user accounts
  ✓ Update system settings

DELETE ACCESS:
  ✓ Delete any document
  ✓ Delete users
  ✓ Delete classes
```

### Firestore Security Rules

**Location**: `firestore.rules`

```firestore
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    
    // Helper functions
    function isSignedIn() {
      return request.auth != null;
    }

    function getUser(uid) {
      return get(/databases/$(database)/documents/users/$(uid)).data;
    }

    function isAdmin() {
      return isSignedIn() && getUser(request.auth.uid).role == 'admin';
    }

    function isApprovedTeacher() {
      let ud = getUser(request.auth.uid);
      return isSignedIn() && ud.role == 'teacher' && ud.teacherStatus == 'approved';
    }

    function isClassTeacher(classCode) {
      let c = get(/databases/$(database)/documents/classes/$(classCode)).data;
      return isSignedIn() && c != null && 
             (c.teacherId == request.auth.uid || 
              (c.teachers != null && c.teachers.any(t => t.uid == request.auth.uid)));
    }

    // USER RULES
    match /users/{userId} {
      allow read: if isSignedIn() && request.auth.uid == userId;
      allow read: if isAdmin();
      allow create: if isSignedIn() && request.auth.uid == userId;
      allow update: if isSignedIn() && request.auth.uid == userId;
      allow delete: if isSignedIn() && request.auth.uid == userId;
      allow update: if isAdmin();
    }

    // CLASS RULES
    match /classes/{classCode} {
      allow read: if isSignedIn();
      allow create: if isApprovedTeacher();
      allow update, delete: if isClassTeacher(classCode);
      
      match /joinRequests/{studentId} {
        allow read: if isClassTeacher(classCode) || isAdmin() || 
                       request.auth.uid == studentId;
        allow create: if isSignedIn() && request.auth.uid == studentId;
        allow update: if isClassTeacher(classCode);
        allow delete: if isClassTeacher(classCode) || 
                         request.auth.uid == studentId;
      }
    }

    // ASSIGNMENT RULES
    match /assignments/{assignmentId} {
      allow read: if isSignedIn();
      allow create: if isApprovedTeacher();
      allow update: if isApprovedTeacher() && 
                       resource.data.teacherId == request.auth.uid;
      allow delete: if isApprovedTeacher() && 
                       resource.data.teacherId == request.auth.uid;
    }

    // SUBMISSION RULES
    match /assignmentSubmissions/{submissionId} {
      allow read: if isSignedIn() && 
                     (resource.data.studentId == request.auth.uid || 
                      isClassTeacher(resource.data.classCode) ||
                      isAdmin());
      allow create: if isSignedIn();
      allow update: if isSignedIn() && 
                       resource.data.studentId == request.auth.uid;
      allow update: if isClassTeacher(resource.data.classCode);
    }
  }
}
```

### Firestore Query Patterns

```javascript
// Get student's assignments for a class
db.collection('assignments')
  .where('classCode', '==', classCode)
  .where('status', '==', 'published')
  .orderBy('dueDate', 'asc')

// Get all quiz submissions for a quiz
db.collection('quizSubmissions')
  .where('quizId', '==', quizId)
  .orderBy('submittedAt', 'desc')

// Get student's grades in a class
db.collection('gradeRecords')
  .where('studentId', '==', studentId)
  .where('classCode', '==', classCode)
  .limit(1)

// Get pending teacher approvals
db.collection('users')
  .where('role', '==', 'teacher')
  .where('teacherStatus', '==', 'pending')

// Get class join requests
db.collection('classes')
  .doc(classCode)
  .collection('joinRequests')
  .where('status', '==', 'pending')
  .orderBy('requestedAt', 'asc')
```

## Performance Optimization

### Data Size Reduction
1. **Archive old data**: Move completed quizzes/assignments to archive collection
2. **Paginate collections**: Load data in batches (e.g., 20 items per page)
3. **Denormalize critical fields**: Store class name in assignments for quick display
4. **Store only references**: Use UIDs/IDs instead of full user objects

### Query Optimization
```javascript
// ❌ INEFFICIENT: Multiple reads
const students = [];
for (const studentId of class.studentIds) {
  const doc = await db.collection('users').doc(studentId).get();
  students.push(doc.data());
}

// ✅ EFFICIENT: Batch read
const studentDocs = await db.collection('users')
  .where(firebase.firestore.FieldPath.documentId(), 'in', class.studentIds)
  .get();

// ❌ INEFFICIENT: Query without limits
const allAssignments = await db.collection('assignments').get();

// ✅ EFFICIENT: Paginated query
const firstPage = await db.collection('assignments')
  .where('classCode', '==', classCode)
  .limit(20)
  .get();
```

### Caching Strategy
```javascript
// React Query/SWR implementation
const { data: assignments } = useQuery({
  queryKey: ['assignments', classCode],
  queryFn: () => getClassAssignments(classCode),
  staleTime: 5 * 60 * 1000, // 5 minutes
  cacheTime: 30 * 60 * 1000 // 30 minutes
});
```

### Firestore Pricing Optimization
| Operation | Cost | Optimization |
|---|---|---|
| Read | $0.06 per 100K | Use `where` clauses, pagination |
| Write | $0.18 per 100K | Batch writes, update only changed fields |
| Delete | $0.02 per 100K | Archive instead of delete |
| Storage | $0.18 per GB | Compress files, clean old data |

## Backup & Recovery

### Backup Strategy

1. **Automated Backups** (via Firebase)
   - Daily snapshots
   - 30-day retention
   - Geographic redundancy

2. **Export to Cloud Storage** (Monthly)
   ```bash
   gcloud firestore export gs://backups/firestore-backup-$(date +%Y%m%d)
   ```

3. **Database Replication** (Optional)
   - Real-time sync to secondary database
   - For disaster recovery

### Recovery Procedures

**Restore Single Document**:
```javascript
// Export → modify → reimport
const backup = exportedData.find(d => d.id === 'specific-doc-id');
await db.collection('users').doc('user-id').set(backup.data);
```

**Restore Entire Collection**:
```bash
gcloud firestore import gs://backups/firestore-backup-20260517/firestore.export
```
